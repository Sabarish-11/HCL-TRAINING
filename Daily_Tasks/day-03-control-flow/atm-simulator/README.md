# Day 3 - Control Flow + Maven

## Project: ATM Simulator

This project demonstrates Java control-flow concepts and Maven project management by implementing a console-based ATM simulator.

---

## Objectives

The project demonstrates:

- `if / else`
- `switch`
- `while`
- `do-while`
- Traditional `for`
- Enhanced `for`
- `break`
- `continue`
- Input validation
- Maven project structure
- Maven parent POM
- Maven modules
- Maven dependency scopes
- Maven lifecycle
- Maven profiles

---

## ATM Features

The ATM provides the following menu options:

1. Check Balance
2. Deposit
3. Withdraw
4. Mini Statement
5. Exit

---

## PIN Authentication

The ATM requires a 4-digit PIN before accessing the menu.

### Correct PIN

```text
1234
Security Rule

The user gets a maximum of 3 attempts.

After three incorrect attempts:

Too many incorrect attempts. Card blocked.

Invalid non-numeric PIN input is handled without crashing the application.

Control Flow Demonstration
if / else

Used for:

PIN validation
Deposit validation
Withdrawal validation
Balance checking
switch

Used to process the ATM menu options.

while

Used for the PIN authentication loop.

The loop allows a maximum of three PIN attempts.

do-while

Used for the ATM menu so that the menu continues until the user selects Exit.

Enhanced for

Used to display the transaction history in the Mini Statement.

Example:

for (String transaction : transactions) {
    System.out.println(transaction);
}
break

Used to:

Exit the PIN loop after successful authentication
Exit the ATM menu
Exit switch cases
continue

Used to:

Handle invalid PIN input
Handle invalid menu input
Handle invalid deposit amounts
Handle invalid withdrawal amounts

Maven Profiles

and:

Running the Application

First build the project:

mvn clean package

Then run the ATM application:
