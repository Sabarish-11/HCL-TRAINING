# Monthly Usage Analyser

A Java fundamentals project created as part of HCL Training Day 2.

## Concepts Covered

- Java primitive data types
- Variables and constants
- 1-D arrays
- 2-D arrays
- Operators and ternary operator
- Operator precedence
- Widening and narrowing type casting
- Integer overflow prevention using `long`
- Floating-point precision
- Git and GitHub fundamentals

## Project Features

The Monthly Usage Analyser calculates:

- Total monthly usage
- Average usage
- Maximum usage
- Minimum usage
- Usage grade
- Slab amount
- Usage data for three houses

This project follows the basic Git workflow:

1. Working directory
2. Staging area
3. Commit
4. Remote repository

The project uses `.gitignore` to prevent compiled Java files and build output from being committed.
