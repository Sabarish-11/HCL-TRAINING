# Day 1 – Java Platform Basics

## Objective

Understand the Java platform, JVM architecture, compilation and execution flow, and basic Agile/Scrum concepts.

## Topics Covered

* JDK, JRE and JVM
* JVM architecture
* Java compilation and execution
* Java bytecode
* Class Loader
* Runtime Data Areas
* Execution Engine
* Interpreter
* JIT Compiler
* Garbage Collection
* Agile and Scrum basics
* Sprints
* User Stories
* Story Points
* Definition of Done

## Practical Task

Created a Java program named `PlatformInfo.java` to display:

* Java version
* Operating system
* Number of available processors
* Maximum heap memory
* Free heap memory

## Commands Used

```bash
javac PlatformInfo.java
java PlatformInfo
javap -c PlatformInfo
java -verbose:class PlatformInfo
```

## Java Execution Flow

```text
PlatformInfo.java
       |
       | javac
       v
PlatformInfo.class
       |
       | JVM
       v
Bytecode Execution
```
